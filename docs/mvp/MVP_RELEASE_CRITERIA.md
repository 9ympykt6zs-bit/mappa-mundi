# MVP Release Criteria

Atlas Quest MVP can ship when all release gates below are satisfied.

## Release Gates

- [ ] Normal user flow has no visible developer, debug, POC, or legacy SVG links.
- [ ] Root URL opens the app through `index.html`.
- [ ] Main navigation is not broken.
- [ ] Journey Mode works start-to-finish for World Foundations.
- [ ] Journey Mode works start-to-finish for at least the first United States activity.
- [ ] Auto-advance or manual continue between Journey steps works reliably.
- [ ] Continue/resume Journey behavior is clear and not misleading.
- [ ] Study Preview works.
- [ ] Study Practice works.
- [ ] Study Preview and Study Practice do not corrupt Journey progress.
- [ ] Free Play does not break normal gameplay or Journey progress.
- [ ] Mobile tap-select/tap-place is usable.
- [ ] Selecting an answer chip does not reveal the correct target.
- [ ] Correct and incorrect feedback work after placement attempts.
- [ ] Reset works.
- [ ] Completion behavior works.
- [ ] Progress save/resume works.
- [ ] No major visible text corruption or mojibake remains.
- [ ] Ocean rendering is consistent enough for the Continents and Oceans activity.
- [ ] The app can be deployed and opened from the root URL.

## Release Principle

Do not block MVP on more content. Block MVP only on stability, clarity, mobile usability, misleading UI, or broken primary flows.
