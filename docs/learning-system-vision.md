# Adaptive Cumulative Learning System Vision

The long-term goal is for Mappa Mundi to teach the user every item in the app through a guided cumulative learning path.

The user should be able to open the app and continue where they left off. The app should choose what they need next instead of requiring the user to decide what to study.

The system should:
1. Review previously introduced items that are due or shaky.
2. Introduce a small number of new items.
3. Practice those items through adaptive Memory Trail sessions.
4. Mix old items into new sessions so earlier knowledge is not lost.
5. Periodically evaluate learning through Journey checkpoints.
6. Advance the learner through a path until they complete a journey, region, or custom goal.

Important concepts:
- Activity: existing content unit, such as Western Europe or US Capitals.
- Memory Trail: adaptive practice mode used to learn and review targets.
- Journey: challenge/checkpoint mode used to evaluate progress.
- Learning Path: the cumulative course-like progression through app content.
- Covered item: any item the user has already been introduced to.
- Due item: a covered item that should be reviewed again.
- Weak item: an item the user has missed or struggled with.
- New item: an item not yet introduced to the learner.

Long-term behavior:
- All covered items may appear later in the learning path.
- Previously learned countries should not disappear forever.
- The system should favor high-confidence learning, not constant failure.
- Wrong answers should be rare enough that users, especially children, do not get frustrated.
- The app should gradually expand the learner’s known world.

Possible future session mix:
- Known/due review items
- Shaky items
- A small number of new items
- Final confidence-building review
- Periodic Journey checkpoint

The product promise:
Mappa Mundi remembers what the learner knows, what they are starting to forget, and what they are ready to learn next.
