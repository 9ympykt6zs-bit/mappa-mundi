Try Memory Trail?

First, learn a small group of places. Then practice finding them and naming them from memory.

Memory Trail helps you learn a small group of places, then practice them from memory. First, you'll see and hear the places in a short Learn phase. Then you'll practice in two ways: find the place named by the app, and name the highlighted place using the answer chips. If you miss one, Memory Trail will bring it back for review. The session adjusts as you play so you get more practice with places that are harder for you.
