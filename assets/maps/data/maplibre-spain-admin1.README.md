# Spain Admin-1 Source

`maplibre-spain-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Natural Earth's Spain Admin-1 features are province-like features with autonomous-community region metadata.
- Atlas Quest aggregates those province polygons into Spain's autonomous communities and keeps Ceuta and Melilla as autonomous-city targets.
- User-facing labels use common English forms such as `Basque Country`, `Navarre`, `Castile and León`, and `Valencian Community`.
