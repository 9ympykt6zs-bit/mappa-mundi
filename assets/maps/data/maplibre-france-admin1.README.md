# France Admin-1 Source

`maplibre-france-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Natural Earth's France Admin-1 features are departments in this source, so Atlas Quest aggregates metropolitan departments into modern regions for MVP region activities.
- The activity source includes only metropolitan France regions so Europe/France cameras remain focused and are not distorted by overseas geometry.
- Overseas regions are intentionally left for a future special activity once app-wide overseas-region camera and placement handling is designed.
