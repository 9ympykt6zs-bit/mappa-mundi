# Japan Admin-1 Source

`maplibre-japan-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Filtered to Japan's 47 prefecture-level divisions for Atlas Quest MVP political-division activities.
- User-facing labels use the common English forms requested for the activity set, such as `Hokkaido`, `Tokyo`, `Kyoto`, `Osaka`, `Hyogo`, `Kochi`, and `Oita`.
- Source properties preserve the Natural Earth names, including macron forms where present.
