# Italy Admin-1 Source

`maplibre-italy-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Natural Earth's Italy Admin-1 features are provinces in this source, so Atlas Quest aggregates them into modern regions for MVP region activities.
- User-facing labels use common English forms such as `Aosta Valley`, `Piedmont`, `Apulia`, `Sicily`, and `Sardinia`.
