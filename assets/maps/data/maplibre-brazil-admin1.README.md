# Brazil Admin-1 Source

`maplibre-brazil-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Filtered to Brazil's 26 states and Federal District for Atlas Quest MVP political-division activities.
- User-facing labels preserve Portuguese diacritics.
- Distrito Federal is labeled "Distrito Federal / Federal District" in activities for clarity.
