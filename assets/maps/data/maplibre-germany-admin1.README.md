# Germany Admin-1 Source

`maplibre-germany-admin1.geojson` is derived from Natural Earth `ne_10m_admin_1_states_provinces` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_1_states_provinces.geojson

Natural Earth data is public domain.

Notes:
- Filtered to Germany's 16 states / Länder for Atlas Quest MVP political-division activities.
- User-facing labels use common English names where appropriate, such as `Bavaria`, `Lower Saxony`, `North Rhine-Westphalia`, and `Rhineland-Palatinate`.
- `Baden-Württemberg` keeps its standard German spelling in the user-facing label.
