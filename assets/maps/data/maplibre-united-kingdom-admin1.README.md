# United Kingdom Map Unit Source

`maplibre-united-kingdom-admin1.geojson` is derived from Natural Earth `ne_10m_admin_0_map_units` GeoJSON:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_admin_0_map_units.geojson

Natural Earth data is public domain.

Notes:
- Filtered to the four UK countries: England, Scotland, Wales, and Northern Ireland.
- This MVP activity intentionally does not include counties, councils, London boroughs, or local authorities.
- The source is treated as a political-division source in Atlas Quest even though the Natural Earth layer is map units rather than the Admin-1 states/provinces layer.
