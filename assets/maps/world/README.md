# World Map Source

This world map is generated from Natural Earth Admin 0 country data.

- Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson
- License/status: Public domain / Natural Earth public domain data
- Projection: equirectangular

The SVG in this folder is generated so future locations can be placed directly from
real longitude/latitude coordinates without guessing the projection later.
